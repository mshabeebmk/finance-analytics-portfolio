## Project 02 — Accounts Receivable & Cash Flow Dashboard

An accounts receivable and collections analysis project using fictional FY2025 data (90 invoices, 10 customers).

### Key Analysis
- AR ageing by customer (Not due / 1-30 / 31-60 / 61-90 / 90+)
- DSO and Collection Effectiveness Index
- Credit-limit checks and 90+ day risk flags
- 3-month cash collection forecast with at-risk balance
